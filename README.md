## 📊 Project Architecture & Pipeline

This repository contains a full Google Colab data science pipeline built using Python, Pandas, and NumPy to analyze and simulate optimal hostel room allocation metrics using tabular datasets.

### Core Implementation Stages:

1. **Data Cleaning & Preprocessing:** Handling missing value imputations, cleaning student demographic records, and normalizing categorical parameters.
   
2. **Exploratory Data Analysis (EDA):**
   Utilizing statistical libraries to identify bottlenecks in current room utilization rates and mapping out spatial distribution efficiency.

3. **Feature Engineering:**
   Creating optimized distance and allocation-priority metrics to segment student datasets cleanly before feeding them into downstream models.
